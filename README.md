## Dependencias
- Node.js
- npm
- pnpm
- Prisma ORM

```bash
# instalar dependencias
pnpm install
# gerar client Prisma
pnpm run prisma:generate
# rodar em modo dev
pnpm run dev
# formatar e indentar codigo conforme config prettier
pnpm prettier . --write
# validacao prettier
pnpm prettier . --check
```
